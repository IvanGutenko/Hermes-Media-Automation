# Shorts для @WrongDevp: пост → сценарий → новые сцены → русская речь

Аватар больше не используется. Не прикреплять `avatar.png`, старые ролики или
референсы персонажа. Показывать предметы, интерфейсы и действия по теме поста.

## Сценарий

Источник — переданный пост/статья/тема либо реально опубликованный пост из БД.
Не выдумывать бесплатный доступ, цены, личный опыт или результаты тестов.
Короткая тема не требует длинного видео: обычно достаточно трёх сцен — хук,
конкретная демонстрация, переход в Telegram. Для каждой сцены JSON содержит:

- `video_prompt_en`: английское описание одного действия, композиции, камеры и света.
  Например: `Close-up of a laptop screen with a subscription card. A cursor activates
  the card; its border lights up as the camera pushes closer. Soft daylight, clean
  product cinematography, a clear screen area for an editorial overlay.`
- `voiceover_ru`: русский текст для речи, только кириллические буквы и пробелы.
  Все числа и версии — словами. Названия произносятся по-русски только в этом поле.
- `on_screen_text_ru`: короткая русская подпись; бренды и версии сохраняют оригинал:
  `ChatGPT`, `OpenAI`, `DeepSeek V4.1`. Точные подписи добавляет монтаж, а не Veo.
- `edit_note_ru`: конкретная монтажная инструкция для этой сцены.

Дерзкий живой хук без скучных оговорок и пустого хайпа. Речь соответствует
изображению в каждой сцене. В финале — призыв в Telegram-канал и «ссылка в описании»;
на экране — `@WrongDevp`. Слова «полный гайд» произносятся только если источник сам является
гайдом, инструкцией, набором промптов или подборкой ресурсов (поле `cta: "guide"`). Для новостей,
исследований, релизов и происшествий — `cta: "links"`: «Подробности и все ссылки…». Сомневаешься —
`links`: нельзя обещать гайд, которого нет в материале.

`youtube_meta` содержит русский цепляющий title до семидесяти символов с оригинальным
написанием брендов, описание с `https://t.me/WrongDevp` и релевантные теги.
Транслитерация и числа словами относятся только к речи, не к title и подписям.

## Генерация и монтаж

Flow работает в прямом режиме Video, Veo 3.1 - Lite, 9:16, один результат.
Пул видеосцен: основной Flow → второй Flow → Google Vids (Omni, 720p, 9:16,
восемь секунд). Второй Flow сейчас отклоняет регион своего аккаунта; отказ
сохраняется отдельно, основной Flow и Vids продолжают работать. Сценарий не
подменяется для обхода отказа. Покупка подписок и кредитов не выполняется.
Переход разрешён только после явного отказа по доступности или кредитам.
Неопределённый результат после отправки сначала восстанавливается в том же
проекте/документе; новый генератор автоматически не запускается.
Каждая сцена — отдельная новая генерация. Английский промпт не содержит русских
реплик. Текущий режим обоих каналов — `audio_mode=vids`: единая русская озвучка
в Google Vids через сохранённую серверную сессию. Голоса Knox, Elio и Holt
распределяются по сохранённым назначениям `data/voice_experiments.json`;
повтор задания не меняет голос. Это доступ аккаунта Vids,
без подключения платного API TTS. Текст, документ и полученный файл закреплены
за заданием; изменение текста создаёт отдельную речевую версию.
Отдельный режим Gemini API (`Orus`) остаётся доступен только явно, со своей квотой.
Инструкции не являются частью произносимого текста. Американского TTS-fallback нет.

Проверяется новая карточка по идентификатору, отсутствовавшему до запроса,
скачивание, хеш файла, вертикальный формат, длительность и соответствие запросу.
У каждой сцены — собственные запрос, файл и receipt. Ошибка завершает сборку;
старые `generated_flow_video.mp4`, `flow_last_run.json` и `output/scenes/` не являются
запасным результатом. Зацикливание и замораживание видео запрещены.

Сначала сценарий проходит независимую проверку фактов и условий исходного поста.
Затем синтезируется речь всех сцен. Автоматически проверяются русский язык,
произнесённые слова, числовые значения, отрицания, естественность и акцент.
Границы сцен и титров берутся из реальной записи речи. Сегмент длиннее восьмисекундного клипа
требует сокращения сценария до использования видеокредитов. FFmpeg обрезает каждый
новый клип под свою речь, добавляет подписи и склеивает сцены. Звук Veo заменяется
точной русской озвучкой, поэтому лишние реплики видеомодели не попадают в результат.
Перед публикацией отдельно проверяется готовый MP4: соответствие сцен речи,
действия и монтаж, читаемость подписей. Файл после проверки должен иметь тот же SHA.
Успех — существующий готовый MP4 и `manifest.json`, не нажатая кнопка генерации.

Не добавлять аватара, футер «Источник» и домен источника поверх видео.
Для Мигратории использовать её Telegram и YouTube; для WrongDev — @WrongDevp.
Telegram получает редакционные посты и исходные медиа постов, а не копии Shorts.
Темы политики, правительства РФ, повесток, мобилизации, войны, санкций и
преследования исключены на отборе, написании и публикации. Не маскировать их рерайтом.

Согласованное расписание публикации исполняет серверный `media_worker.py` через
`video-autoposter.timer`. Интервал — три часа от фактической подтверждённой публикации;
неудачная генерация не считается
публикацией и не запускает серию догоняющих загрузок. Вкладки после успешного
экспорта/публикации закрываются, cookies аккаунтов сохраняются в серверном профиле.

## Команды

```bash
# Подготовить сценарий
/home/gut/hermes-workspace/tg_autoposter/.venv/bin/python /home/gut/hermes-workspace/tools/video_factory_tool.py script "Текст поста или тема"

# Полный цикл с сохранением превью
/home/gut/hermes-workspace/tg_autoposter/.venv/bin/python /home/gut/hermes-workspace/tools/video_factory_tool.py run "Текст поста или тема" flow

# Взять конкретный опубликованный пост из БД
/home/gut/hermes-workspace/tg_autoposter/.venv/bin/python /home/gut/hermes-workspace/tools/video_factory_tool.py run --post-id 26

# Отдельный новый клип, только визуальный промпт
/home/gut/hermes-workspace/tg_autoposter/.venv/bin/python /home/gut/hermes-workspace/tools/video_factory_tool.py generate flow "English visual prompt" "Title"
```

`run` по умолчанию сохраняет превью. `--publish` и отдельная команда `upload`
используются только по поручению владельца на публикацию. Таймер, вызывающий
`run` без `--publish`, также сохраняет превью. Vids не объявляется успешным без
проверяемого готового MP4. Полный цикл использует пул Flow/Vids; отдельная
команда `generate flow` обращается только к Flow.

Серверный Chrome использует PAC для всех связанных доменов Google, а не только
страницы Flow. Приватный мост передаёт запросы слушателю Mihomo `media-browser`
(127.0.0.1:17893), селектор `MEDIA` независим от `ANTIGRAVITY`. Рабочий узел
проверяется по фактическому доступу к генерации, а не только HTTP 200.

Артефакты каждого запуска: `video_factory/output/runs/<run_id>/` — `script.json`,
`script.md`, речевые WAV, `.tts.json`, сцены, `short.mp4`, `manifest.json`.
`latest_script.*` — удобная копия последнего сценария, не результат текущей генерации.
Готовые результаты для владельца сохранять в `/home/gut/hermes-workspace/output/`.

## Источники рекомендаций

- Google: https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/best-practice
  — один конкретный момент на короткий клип, отдельные клипы для разных действий.
- Google DeepMind: https://deepmind.google/models/veo/prompt-guide/
  — предмет, действие, камера, свет, явное управление звуком.
- Google TTS: https://ai.google.dev/gemini-api/docs/speech-generation
  — отдельная настройка голоса, речевой текст и инструкции подачи.
- Google Vids: https://support.google.com/docs/answer/15609411?hl=en
  — доступ к AI-функциям и русской озвучке зависит от аккаунта и его плана.

Если прервалось скачивание уже созданной сцены, можно продолжить **тот же** запуск:

```bash
/home/gut/hermes-workspace/tg_autoposter/.venv/bin/python /home/gut/hermes-workspace/tools/video_factory_tool.py run --resume <run_id>
```

Восстановление сверяет исходный пост, текст сцены и идентификатор её нового
результата. Оно не подставляет видео из другого запуска. Уже полученная речь
используется только из этого задания с совпадающими текстом, моделью и голосом.
Пустое скачивание повторяется до трёх раз без повторной видеогенерации.

## Изображения постов и обратная связь

Если у исходного поста нет медиа, бот вызывает `post_images.ensure_image`.
Английский предметный промпт привязан к бренду и исходному посту; Google Pics
создаёт новый документ и новое изображение. Сохраняются документ, запрос,
исходный JPEG, SHA и независимая проверка соответствия тексту.
Исходные фотографии не заменяются. Один проверенный файл используется
для Telegram, фото-поста VK и обложки статьи по тому же материалу.
Второй сохранённый аккаунт Pics разрешён только после явного отказа первого;
после неопределённого ответа возобновляется тот же документ.

Публикации YouTube завершаются только с открытым доступом и публичной
проверкой автора, заголовка и ссылки. Приватный этап загрузки не является
завершённой публикацией. Отправка с потерянным ответом сверяется по квитанции;
повторная отправка без проверки запрещена.

`media-analytics.timer` повторяет неполный сбор каждые пятнадцать минут;
полный свежий замер используется в течение часа. `content_feedback.py`
сохраняет доступные показатели Telegram, YouTube Studio, VK, Дзена и Reddit.
Показы, просмотры, дочитывания, оценки и комментарии не подменяют друг друга.
Отсутствующий показатель не равен нулю; старый замер сохраняет исходное время.
Редактор и сценарист получают эти данные через `editorial_brief`.
Сравнивать голос нужно по удержанию роликов одного возраста; несколько
публикаций не устанавливают предпочтение аудитории.

`media-health.timer` проверяет просроченные публикации, ошибки и свежесть задач,
живой браузер и транспорт Google/YouTube. При поломке маршрута `MEDIA`
проверяет другие существующие узлы через `PROBE`, затем проверяет уже выбранный
рабочий маршрут. Переключение происходит только без активной браузерной задачи.
Доступность транспорта не доказывает доступность генерации: её подтверждает
только настоящий новый клип. Каждый браузерный процесс ограничен по времени
внутри контейнера; таймаут клиента Docker не должен оставлять владельца блокировки.
