# Hermes Media Automation

Интеграция Hermes Agent с Telegram и инструментами медиапроизводства: подготовка контента, генерация видео, проверка качества, публикация и сбор аналитики.

**Стек:** Python · JavaScript · Telethon · Playwright · FFmpeg · AI API/CLI · systemd · Docker.

## Состав

- `plugins/` — адаптеры AI-провайдеров и CLI для Hermes Agent.
- `tools/` — настройка интеграций, синхронизация выбранного контекста и инструменты медиа.
- `tg_autoposter/` — сбор источников, подготовка постов, дедупликация и Telegram-управление.
- `video_factory/scripts/` — сценарии, изображения, озвучка, рендеринг, проверки качества и адаптеры публикации.
- `video_factory/tests/`, `tests/` — существующие проверки; `config/` — примеры systemd-служб.

Сам Hermes Agent — внешняя зависимость. В этом репозитории опубликованы собственные инструменты и адаптеры, а не копия ядра агента.

## Развёртывание

Проект рассчитан на настроенное серверное окружение Hermes. Для переноса требуются собственные авторизации AI/социальных сервисов, FFmpeg, браузерная автоматизация и адаптация путей в конфигурациях. `tg_autoposter/requirements.txt` описывает базовые зависимости Telegram-компонента.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r tg_autoposter/requirements.txt
cp tg_autoposter/.env.example tg_autoposter/.env
cp tg_autoposter/config.example.yaml tg_autoposter/config.yaml
```

Перед запуском настройте собственные источники, целевой канал, разрешённых пользователей и провайдеры. Авторизации и пути к runtime-файлам настраиваются отдельно; установка базовых зависимостей не заменяет подготовку окружения всего медиаконвейера.

## Публичная версия

Серверные компоненты скопированы **2 ноября 2026 года**; локальные адаптеры и проверки добавлены из рабочей папки проекта. При совпадении путей приоритет отдан серверной копии. Личные заметки, аккаунты, VPN-подписки, OAuth-файлы, браузерные профили и готовые медиа исключены. Оставшиеся секреты в скриптах публичной копии заменены чтением из окружения.
